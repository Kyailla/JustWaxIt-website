# JustWaxIt Website

Production-ready Next.js 15 website for JustWaxIt, a luxury waxing studio in Twin Falls, Idaho.

## Stack
- Next.js 15 App Router
- React + TypeScript
- Tailwind CSS
- Local SEO metadata and JSON-LD schema
- Vercel-ready scripts

## Development
```bash
npm install
npm run dev
```

## Environment
- `NEXT_PUBLIC_SITE_URL` - canonical production URL
- `NEXT_PUBLIC_BOOKING_URL` - booking link override
- `NEXT_PUBLIC_GA_ID` - Google Analytics measurement ID placeholder
